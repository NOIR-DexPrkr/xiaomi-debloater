NOIRXD

Noir - Xiaomi Debloater

Elimina el bloatware, los anuncios y la telemetría de tus teléfonos Xiaomi, Redmi y POCO con MIUI y HyperOS. Funciona por ADB, sin root y sin desbloquear el bootloader: cada paquete está clasificado por riesgo y todas las acciones se pueden deshacer.

¿Por qué un debloater solo para Xiaomi?

4 razones

640+ paquetes de Xiaomi

Cada paquete tiene una descripción clara y una calificación de riesgo: seguro, precaución o peligroso. Para MIUI 12–14 y HyperOS 1, 2 y 3.

Actualizado con cada versión

La app descarga la última lista de paquetes, así que el bloat nuevo de HyperOS se reconoce sin reinstalar nada.

Reversible

Las apps se eliminan solo para tu usuario. Restaura cualquiera desde la pestaña Eliminadas.

Sin root

Todo funciona por ADB con la depuración por USB. Tu bootloader sigue bloqueado y las actualizaciones OTA siguen funcionando.

Cómo empezar

5 pasos
  1. 01

    Instala ADB: brew install android-platform-tools (macOS), winget install Google.PlatformTools (Windows) o sudo apt install adb (Linux).

  2. 02

    En el teléfono, ve a Ajustes > Acerca del teléfono y toca Versión de MIUI o Versión del OS 7 veces.

  3. 03

    Activa Ajustes > Ajustes adicionales > Opciones de desarrollador > Depuración por USB.

  4. 04

    Conecta el teléfono por USB y toca Permitir en el aviso de depuración.

  5. 05

    Abre NoirXD, empieza por la pestaña Bloatware y elimina los paquetes marcados como seguros.

Descargas

Versiones

Windows

Ejecutable portátil: no requiere instalación. Ábrelo y conecta el teléfono por USB. Para ADB: winget install Google.PlatformTools.

Descargar x64 Descargar ARM64

x64 sirve para la mayoría de los PC. Elige ARM64 solo si tu equipo tiene un procesador ARM (por ejemplo, Snapdragon).

macOS

App universal en .zip: un solo archivo sirve para Intel y Apple Silicon. Extrae y arrastra NoirXD.app a Aplicaciones. Para ADB: brew install android-platform-tools.

Descargar .zip (universal)

Todavía sin notarizar: si macOS la bloquea al abrir, ejecuta xattr -dr com.apple.quarantine "/Applications/NoirXD.app", o ábrela una vez y luego desde Ajustes > Privacidad y seguridad.

Linux

Para Ubuntu 22.04+, Debian 12+, Fedora 39+ y sus derivados, con GTK 3 y WebKitGTK 4.1. Para ADB: sudo apt install adb.

Preguntas frecuentes

5 preguntas
¿Es seguro debloatear un teléfono Xiaomi?

Los paquetes se eliminan solo para el usuario actual, así que se pueden restaurar. Los paquetes marcados como peligrosos pueden romper llamadas, SIM, Ajustes o el arranque; no los toques y haz una copia de seguridad antes.

¿Necesito root o un bootloader desbloqueado?

No. NoirXD funciona por ADB con la depuración por USB activada.

¿Cómo restauro una app eliminada?

Usa Restaurar en la pestaña Eliminadas de la app, o ejecuta adb shell cmd package install-existing <paquete>. Un restablecimiento de fábrica también restaura todo.

¿Funciona con HyperOS 3?

Sí. La lista incluye los paquetes de HyperOS 3 del Xiaomi 15 Ultra, que comparten la mayoría de los modelos actuales de Xiaomi, Redmi y POCO. ¿Falta un paquete? Repórtalo.

¿En qué se diferencia de Universal Android Debloater?

UAD-ng cubre todas las marcas. NoirXD se enfoca solo en Xiaomi, con la lista versionada por MIUI/HyperOS y una guía específica de Xiaomi.
